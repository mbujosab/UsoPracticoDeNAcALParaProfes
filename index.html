Este repositorio está pensado para compilar documentos LaTeX bajo demanda en un entorno MyBinder/JupyterLab, incluyendo:

  • PythonTeX: ejecutar código Python desde LaTeX y reintegrar los resultados en el PDF.
  • AcroTeX / exerquiz: escritura de ejercicios y (opcionalmente) soluciones agrupadas al final.
  • nacal.sty: paquete con la notación del curso (colocado en tex/nacal/nacal.sty), que a su vez usa paquetes como amsmath, amssymb, esvect, leftidx, pict2e, stackengine, xparse, xspace.

1. Abrir en Binder

  1. Pulsa el badge de Binder (rellena <OWNER> y <REPO> con tu repo):
https://mybinder.org/v2/gh/<OWNER>/<REPO>/HEAD
  1. Espera a que cargue JupyterLab.
  2. Abre Terminal (en JupyterLab: /File → New → Terminal/).

2. Compilar bajo demanda

Para compilar tex/Quiz1-2025-C.tex: 

bash scripts/compila.sh tex/Quiz1-2025-C.tex

o 

bash scripts/build_latex.sh tex/Quiz1-2025-C.tex

El PDF resultante quedará en:

  • tex/Quiz1-2025-C.pdf

y una copia en el directorio raiz

  • Quiz1-2025-C.pdf

Puedes abrirlo desde el explorador de archivos de JupyterLab.

3. Estructura del repo (resumen)

  • binder/apt.txt: dependencias del sistema (TeX Live, latexmk, etc.)
  • binder/environment.yml: entorno Python (para PythonTeX)
  • binder/postBuild: ajustes al construir Binder (permisos, etc.)
  • scripts/compila.sh: script de compilación (pdflatex → pythontex → latexmk)
  • scripts/build_latex.sh: script de compilación (pdflatex → pythontex → latexmk)
  • tex/nacal/nacal.sty: tu paquete con la notación del curso
  • tex/aux/PreambuloParaExamenes.tex: preámbulo \(\LaTeX{}\) para los examenes
  • tex/aux/InstruccionesQuiz.tex: bloque de código \(\LaTeX{}\) con las instrucciones de los quizes
  • tex/aux/InstruccionesExamenFinal.tex: bloque de código \(\LaTeX{}\) con las instrucciones de los exámenes finales
  • tex/Quiz1-2025-C.tex: documento principal de ejemplo
  • tex/preguntas/2025-intermedio1-C.tex: preguntas usadas en el documento de ejemplo

4. Notas sobre PythonTeX

El flujo habitual requiere varias pasadas:

  1. pdflatex genera auxiliares y los ficheros de trabajo de pythontex
  2. pythontex ejecuta el código Python y produce resultados intermedios
  3. latexmk remata pasadas para referencias/TOC y deja el PDF final

El script scripts/compila.sh implementa ese flujo. También el script scripts/build_latex.sh (sugerido por copilot de GitHub.

Si al ejecutar el script aparece un error del tipo "No encuentro pythontex", revisa el log del terminal y ajusta binder/apt.txt (o dime las últimas ~30 líneas del error y te indico el paquete exacto a añadir).

5. Exerquiz: soluciones al final (plantilla)
