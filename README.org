Este repositorio está diseñado para compilar *documentos LaTeX bajo demanda* en un entorno *MyBinder/JupyterLab*, incluyendo:

- *PythonTeX*: ejecutar código Python desde LaTeX y reintegrar los resultados en el PDF.
- *AcroTeX / exerquiz*: escritura de ejercicios y (opcionalmente) *soluciones agrupadas al final*.
- *nacal.sty*: [[https://github.com/mbujosab/nacal-latex-package][paquete con la notación del curso]] (ubicado en =tex/nacal/nacal.sty=), que a su vez utiliza paquetes como =amsmath=, =amssymb=, =esvect=, =leftidx=, =pict2e=, =stackengine=, =xparse=, =xspace=.

* Compilar bajo demanda
   :PROPERTIES:
   :CUSTOM_ID: compilar-bajo-demanda
   :END:

Para compilar =tex/Quiz1-2025-C.tex= copia uno de los siguientes comandos en un terminal de MyBinder (en JupyterLab: =/File → New → Terminal/=).

- La siguiente variante oculta parte de los resultados al compilar (es un poco más rápida) y copia el =pdf= generado en el directorio raíz:
  #+begin_src sh :eval no
    bash scripts/compila.sh tex/Quiz1-2025-C.tex
  #+end_src

- Esta segunda variante muestra todos los resultados intermedios (mejor para hacer depuración de errores). Sin embargo, es más lenta y deja el =pdf= generado en el subdirectorio =tex=:
  #+begin_src sh :eval no
    bash scripts/build_latex.sh tex/Quiz1-2025-C.tex
  #+end_src
  El PDF resultante estará en: =tex/Quiz1-2025-C.pdf=

Puedes abrir el =pdf= desde el explorador de archivos de JupyterLab.

* Notas sobre PythonTeX
   :PROPERTIES:
   :CUSTOM_ID: notas-sobre-pythontex
   :END:
El flujo habitual requiere varias pasadas:

1. =pdflatex= genera auxiliares y los archivos de trabajo de pythontex
2. =pythontex= ejecuta el código Python y produce resultados intermedios
3. =latexmk= completa las pasadas para referencias/TOC y genera el PDF final

El script =scripts/compila.sh= implementa ese flujo. También el script =scripts/build_latex.sh=.

* Exerquiz: soluciones al final (plantilla)
   :PROPERTIES:
   :CUSTOM_ID: exerquiz-soluciones-al-final-plantilla
   :END:
Si deseas que las soluciones aparezcan al final del documento, 
debes editar =tex/aux/PreambuloParaExamenes.tex= comentando las opciones que no quieres, y descomentando la única opción que deseas.

#+begin_src latex
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% 
%% UNA Y SOLO UNA DE ESTAS TRES LÍNEAS DEBE ESTAR DESCOMENTADA
%
% \usepackage[pdftex,forpaper,nohiddensolutions,solutionsafter,spanish]{exerquiz}   % soluciones a continuación de los enunciados
% \usepackage[pdftex,forpaper,nosolutions,spanish]{exerquiz}                        % sin soluciones (versión de examen para reprografía)
\usepackage[pdftex,forpaper,spanish]{exerquiz}                                    % soluciones al final del documento
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
#+end_src

* Aclaración sobre los entornos y sesiones en MyBinder
   :PROPERTIES:
   :CUSTOM_ID: aclaracion-sobre-los-entornos-y-sesiones-en-mybinder
   :ID:       86707293-0bc5-4097-ab2f-05d76312155a
   :END:

En MyBinder, el entorno que se crea es técnicamente accesible para cualquiera que tenga el enlace activo, pero con limitaciones importantes.

** ¿Es accesible para otros?

Depende del enlace:

- Enlace público (URL que compartes) :: Cualquiera que tenga el enlace puede lanzar _su propia_ instancia independiente del entorno.
- En cuanto a tu sesión específica activa :: No es colaborativa por defecto. Nadie puede entrar en *tu* sesión a menos que compartas exactamente la URL con el token activo (lo cual no es recomendable).

Cada usuario obtiene:

- Su propio contenedor
- Su propio kernel
- Su propia memoria temporal

No hay persistencia compartida entre sesiones.

** ¿Cuánto tiempo tarda en desaparecer?

MyBinder funciona con contenedores efímeros. 
El entorno se elimina tras:

- 10 minutos de inactividad: la sesión se cierra automáticamente.
- Límite máximo aproximado de 6 horas: aunque haya actividad, el contenedor puede reiniciarse.
- Si el servidor necesita recursos, puede terminar antes.

Después de cerrarse:

- Se pierde cualquier archivo no guardado externamente.
- No hay persistencia local.
- Al volver a abrir el enlace, se crea un entorno nuevo desde el repositorio.

** Consideraciones técnicas importantes

- No es adecuado para producción.
- No es persistente.
- Los recursos (CPU/RAM) son limitados.
- Está pensado para demos, docencia y pruebas reproducibles.

** Resumen 

| Pregunta                            | Respuesta                                                                              |
|-------------------------------------+----------------------------------------------------------------------------------------|
| ¿Es el entorno público?             | Sí, si compartes el enlace                                                             |
| ¿Puede alguien entrar en mi sesión? | Muy improbable, necesita el token aleatorio que se ha generado (no lo compartas nunca) |
| ¿Es colaborativo en tiempo real?    | No                                                                                     |
| ¿Guarda cambios?                    | No                                                                                     |
| ¿Cuándo se borra?                   | ~10 min inactivo o máx ~6h                                                             |
